# Perwd

I build tools around Minecraft and Java.

## Projects

**[Onyx PvP](https://github.com/Perwds/onyx-pvp)** is a Fabric client mod for Minecraft PvP with custom skies, shaders, 3D menus and replay tools. The full source is private.

**[Regrind](https://github.com/Perwds/regrind)** is a Java decompiler with a desktop workbench. You can browse a jar, edit the decompiled source, recompile it and export a patched jar. It's plain Java with no dependencies.

**[RegionFlagsPlus](https://github.com/Perwds/RegionFlagsPlus)** adds more than 20 WorldGuard flags to Paper servers, including region effects, teleport-only exits, item blocking and entry limits.

**[Packfinder](https://perwds.github.io/)** searches Minecraft modpacks and mods across Modrinth and CurseForge, with filters the sites don't offer.
